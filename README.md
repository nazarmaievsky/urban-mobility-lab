# Urban Mobility Scenario Lab (прототип)

Реальні вулиці Львова з OpenStreetMap (Overpass API), перекриття ділянки кліком, пошук об'їздів по власному графу доріг, **синтетична** евристична оцінка навантаження (BPR + логіт), підказки щодо світлофорів і точок ручного регулювання.

## Запуск у StackBlitz
1. Найнадійніше: завантаж папку в GitHub-репозиторій і відкрий `https://stackblitz.com/github/<користувач>/<репозиторій>`.
   Альтернатива: на stackblitz.com створи проєкт з шаблоном Vite + React + TypeScript і заміни файли (`package.json`, `index.html`, `vite.config.ts`, `tsconfig.json`, усю папку `src`).
2. StackBlitz сам виконає `npm install` і `npm run dev` (за потреби запусти їх у терміналі).
3. Перший запуск завантажує вулиці з Overpass (5-30 с), далі дані беруться з кешу браузера.
   Кнопка "Спробувати ще раз" з'являється, якщо Overpass не відповів.

## Локально
```
npm install
npm run dev
```

## Як користуватись
1. Клікни на вулицю (сегменти між перехрестями). Кілька кліків = довша ділянка; вона має бути суцільною.
   "Розширити вздовж вулиці" додає сусідні сегменти з тією ж назвою.
2. Зліва задай попит, пропускну здатність, час доби, фонове завантаження, частку закриття.
3. "Запустити симуляцію": на карті з'являться об'їзди (кольорові лінії), перевантажені сегменти (червоний пунктир), 🚦 перехрестя для зміни фаз і 👮 точки, де варто розглянути ручне регулювання.

## Структура
- `src/roadNetwork.ts` — Overpass-запит, кеш у localStorage, виклик OSRM для порівняння
- `src/graph.ts` — граф доріг, Dijkstra, пошук кількох об'їздів
- `src/simulation.ts` — евристична модель; інтерфейс `SimulationEngine` (сюди пізніше підключається SUMO)
- `src/MapView.tsx` — Leaflet + OSM-тайли
- `src/App.tsx` — панель керування і результати

## Що реальне, а що ні
Реальне: геометрія вулиць, класи доріг, наявність світлофорів у OSM, топологія об'їздів.
Синтетичне: усі потоки, пропускна здатність, затримки, v/c, частки об'їздів, зміни фаз світлофорів, точки регулювання.
OSRM у демо лише показує, куди б повів навігатор без урахування перекриття.

## Відомі обмеження
- Усі дороги трактуються як двосторонні; односторонній рух і заборони поворотів не враховані.
- Світлофорні цикли (90 с) і фази — припущення, в OSM їх немає.
- Публічні Overpass/OSRM мають fair-use ліміти: для показу клієнту потрібні кеш або власний інстанс.
- Атрибуція OpenStreetMap відображається на карті, її не прибирай.

## Наступні кроки
Імпорт CSV з реальними потоками, `SumoEngine` на Python-бекенді (TraCI), порівняння сценаріїв у таблиці, експорт Decision Report.
